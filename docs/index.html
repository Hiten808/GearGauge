What it does

Side-by-Side Comparison

Pick any two devices from the MySQL database and get a full specification showdown. JavaScript highlights the better value for RAM, storage, battery and price in green.

index.php

Live Search Catalog

A responsive grid of every device with instant client-side filtering by name, brand, category or processor — no page reloads needed.

browse.php

Accounts & Saved Comparisons

Register and log in with password_hash secured credentials. Save any comparison to your profile and reopen it any time.

profile.php

Admin Dashboard

Role-protected panel to add, edit and delete devices with image upload validation — JPG, PNG or WEBP up to 2 MB.

admin.php

Secure by Design

Every query uses MySQLi prepared statements and every output passes through htmlspecialchars to prevent SQL injection and XSS.

Security

Built From Scratch

Pure HTML5, CSS3, vanilla ES6 JavaScript and procedural PHP 8 — no frameworks, no libraries, fully responsive dark theme.

Run it locally with XAMPP

  1. Install XAMPP and start Apache + MySQL.
  2. Copy the project into C:\xampp\htdocs\GearGauge.
  3. Import database.sql via phpMyAdmin at http://localhost/phpmyadmin.
  4. Open http://localhost/GearGauge/ and log in as admin@specmatrix.com / admin123.
