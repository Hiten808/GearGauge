Pick any two devices from the MySQL database and get a full specification showdown. JavaScript highlights the better value for RAM, storage, battery and price in green.

Dynamic Product Pages

Every device is served by a single reusable template — device.php loads any product by ID with full specifications, pricing and related recommendations.

device.php

Live Search Catalog

A responsive grid of every device with instant client-side search plus category filter chips for Laptops, Phones, Tablets and Android TVs — no page reloads needed.

browse.php

Accounts & Saved Comparisons

Register and log in with password_hash secured credentials. Save any comparison to your profile and reopen or delete it any time.

profile.php

Admin Dashboard

Role-protected panel to add, edit and delete devices with image upload validation — JPG, PNG or WEBP up to 2 MB. Non-admins are redirected to login.

admin.php

Secure by Design

Every query uses MySQLi prepared statements and every output passes through htmlspecialchars to prevent SQL injection and XSS.

Run it locally with XAMPP

  1. Install XAMPP and start Apache + MySQL.
  2. Copy the project into C:\xampp\htdocs\GearGauge.
  3. Import database.sql via phpMyAdmin at http://localhost/phpmyadmin.
  4. Open http://localhost/GearGauge/ and log in as admin@specmatrix.com / admin123.
